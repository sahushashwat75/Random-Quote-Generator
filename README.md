# ✨ Random Quote Generator

A modern and responsive **Random Quote Generator** built using **React.js** and **Vite**. The application displays inspirational quotes from different categories, allows users to search quotes by keywords or author, and generates a new random quote with a single click.

---

## 📌 Features

- 🎲 Generate a random quote instantly
- 🔍 Search quotes by text or author
- 🏷️ Filter quotes by category
- 🎨 Modern and responsive UI
- ⚡ Fast performance with Vite
- ✨ Smooth transitions and clean design

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/sahushashwat75/Random-Quote-Generator.git
```

Go into the project directory

```bash
cd Random-Quote-Generator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```

---

## 🎯 How It Works

1. The application loads a random quote on startup.
2. Users can search quotes using keywords or author names.
3. Users can filter quotes based on categories.
4. Clicking **New Quote** displays another random quote from the filtered results.
5. If no matching quote is found, a friendly "No Quotes Found" message is displayed.
